用途
strip_png_metadata脚本用于批量清理项目内 `src/main/resources/assets/caerula_arbor/textures` 目录下 PNG 图片的元数据。

清理范围
- 递归扫描 `textures` 目录下所有 `.png`
- 只处理带有 PNG 元数据 chunk 的图片
- 当前会识别并清理这些常见元数据 chunk：
  `iTXt`、`tEXt`、`zTXt`、`iCCP`、`eXIf`、`pHYs`、`sRGB`、`gAMA`、`cHRM`、`tIME`

保留内容
- 保留图片像素内容
- 保留图片尺寸
- 对调色板 PNG 会尽量保留 palette 和 transparency

运行方式
在项目根目录打开终端后执行：

python tools/strip_png_metadata.py

依赖
- Python 3
- Pillow

自动安装依赖
- 脚本启动时会先检查是否已安装 `Pillow`
- 如果没有安装，会自动执行 `python -m pip install Pillow`
- 自动安装失败时，脚本会直接报错退出

运行结果
- 脚本会输出扫描数量
- 会输出本次实际启用的工作线程数量
- 会输出实际被处理的图片数量
- 会输出无元数据而跳过的数量
- 会逐行列出被处理的相对路径
- 会逐行列出“扩展名是 `.png` 但文件签名不是 PNG”的自动跳过文件
- 会逐行列出读取失败而跳过的文件

注意事项
- 脚本是原地覆盖文件，请先自行确认工作区改动
- 这个脚本当前面向项目里的 PNG 纹理图，不处理其他格式
- 为了兼顾稳定性与效率，脚本使用流式读取 PNG chunk 判断是否含元数据，命中元数据 chunk 后会立刻停止继续扫描该文件
- 当待扫描文件较多时，脚本会自动启用保守的并行处理；文件较少时仍会退回单线程，避免线程开销反而拖慢处理速度
- 只有确实需要处理的图片才会交给 Pillow 重写，无元数据文件不会再额外构建完整 chunk 列表
